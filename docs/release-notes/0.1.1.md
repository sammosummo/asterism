# Asterism 0.1.1

The 0.1.0 release with one metadata line removed, so that it can be
distributed on PyPI.

## What changed

`Private :: Do Not Upload` is gone from the package classifiers. PyPI rejects
any distribution carrying it, which is what it was there for: nothing could
reach PyPI by accident while the repository was private. The repository is
public and the release is meant to be installed, so the guard has done its job.

Nothing else changed. No source file outside the packaging metadata differs
from 0.1.0, and every number this release computes is the number 0.1.0
computed.

## Evidence

The full release checks were rerun against this commit rather than inherited:
29 scientific pass rules, the four-way cross-platform agreement, and one
synthetic analysis receipt per supported model. `release-evidence.tar.gz`
carries the result, and the [validation record](../validation.md) describes the
comparisons and simulations behind them.

## Artifacts

Two ABI3 wheels, each built from this commit and each installing on CPython

- `asterism-0.1.1-cp313-abi3-manylinux_2_17_x86_64.whl`

## Citing

Cite the version you ran. 0.1.0 remains archived with its own DOI; this
release has its own. `CITATION.cff` carries the concept DOI, which always
resolves to the newest version.

## Post-release evidence correction

**Added on 31 August 2026; the released artefacts are immutable.** The censored
simulation evidence inherited from 0.1.0 used censoring limits selected from
each realised response to force an exact censoring count. It therefore did not
establish interval coverage or test calibration for a fixed measurement limit.
The same qualification correction applies to the affected mixed-model checks.
Historical evidence remains a record of the runs, not support for the withdrawn
claims.

The 0.1.1 one-component numerical fit path has not been changed or shown to
differ. Its corrected fixed-instrument comparison, recovery, coverage and target
checks have since been rerun in development and pass. Boundary mass is treated
as a diagnostic rather than a requirement that the finite-sample atom equal one
half. The corrected fixed-threshold mixed recovery and coverage checks have also
since been rerun in development and pass; this does not alter the immutable
release artefacts. The development several-component analytic and bootstrap
targets both failed their declared rules; neither route is present in the 0.1.1
wheel.
