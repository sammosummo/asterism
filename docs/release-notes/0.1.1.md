# Asterism 0.1.1

The 0.1.0 release with one metadata line removed, so that it can be
distributed on PyPI.

## What changed

`Private :: Do Not Upload` is gone from the package classifiers. PyPI rejects
any distribution carrying it, which is what it was there for: nothing could
reach PyPI by accident while the repository was private. The repository is
public and the release is meant to be installed, so the guard has done its job.

Nothing else changed. No source file outside the packaging metadata differs
from 0.1.0, and every number this release computes is the number 0.1.0
computed.

## Evidence

The full release checks were rerun against this commit rather than inherited:
29 scientific pass rules, the four-way cross-platform agreement, and one
synthetic analysis receipt per supported model. `release-evidence.tar.gz`
carries the result, and the [validation record](../validation.md) describes the
comparisons and simulations behind them.

## Artifacts

Two ABI3 wheels, each built from this commit and each installing on CPython
3.13 and 3.14:

- `asterism-0.1.1-cp313-abi3-macosx_11_0_arm64.whl`
- `asterism-0.1.1-cp313-abi3-manylinux_2_17_x86_64.whl`

`SHA256SUMS` covers both wheels and the evidence archive.
