# Asterism 0.1.0

**Not released.** This is the versioned source for the eventual private GitHub
release page. It must not be published until `release.toml` carries measured
design ranges and configured pass rules, the release commit passes every
ordinary and scientific check, and both saved wheels pass their installed-wheel
matrices.

## Intended scope

Asterism 0.1 is the trait-modelling release described in
`docs/adr/0012-small-analysis-ready-releases.md`. Its supported analyses and
reportable quantities are generated from `release.toml`; capability that remains
importable but lies outside that manifest is not scientifically supported by
this release.

## Evidence

Pending a complete rerun on the exact release commit. Earlier evidence does not
identify the immutable source and dependency state required by the 0.1
contract.

## Compatibility

The planned artifacts are one saved ABI3 wheel for macOS arm64 and one saved
manylinux 2.17 x86_64 ABI3 wheel. Each must install and pass on standard
GIL-enabled CPython 3.13 and 3.14. Checksums will be attached as `SHA256SUMS`.
Those four independent installed-wheel runs do not establish cross-platform
agreement. Release additionally requires normalized Mac and Linux analysis
records to agree exactly on status, refusal codes, boundary states and field
presence, and within pre-written model-specific tolerances on numerical fields.
That comparator and those tolerances are still disabled in `release.toml`.
