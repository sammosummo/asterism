# Asterism 0.1.0

Variance-component models for quantitative genetics: heritability, genetic
correlations, and the models needed for an extended high-frequency audiogram
analysis. Written in Rust with a Python interface, and no BLAS or LAPACK.

## What it fits

Eight analyses are supported in 0.1, each with a page of its own under
[docs/models](../models/):

| Model | Estimand |
| --- | --- |
| One trait, one variance component | Heritability, its interval and test |
| Several covariance components | Mean-diagonal contributions and proportions, coefficients and contrasts |
| Two traits | Genetic correlation, against nought and against one |
| Binary traits | Liability-scale heritability |
| Censored traits | Complete-trait heritability, censoring given rather than inferred |
| Mixed pairs | Genetic correlation between traits of different kinds |
| Gene by environment, measured | Heritability and genetic correlation across a continuous environment |
| Gene by environment, binary | Genetic correlation between two groups |

Relationship matrices can come from anywhere: `relationship_matrix` builds one
from a pedigree and `kinship_classes` splits a pedigree into separate bases,
but every model accepts any finite, symmetric, positive-semidefinite matrix.

Capability that is importable but outside `release.toml` is not part of the
supported set. [docs/outside-support.md](../outside-support.md) says what those
are and why.

## Evidence

Every supported model has been compared against at least one independent
implementation — R's `regress` and `censReg`, SOLAR, MCMCglmm, spaMM, and a
published red deer analysis — and its intervals and tests calibrated by
simulation. The figures, the designs behind them and the rules they were scored
against are in the [validation record](../validation.md).

The release bundle carries the evidence for this exact commit:
`release-evidence.tar.gz` holds the output of every pass rule named in
`release.toml`, the four-way cross-platform agreement, and one synthetic
analysis receipt per supported model.

## Artifacts

Two ABI3 wheels, each built from this commit and each installing on CPython
3.13 and 3.14:

- `asterism-0.1.0-cp313-abi3-macosx_11_0_arm64.whl`
- `asterism-0.1.0-cp313-abi3-manylinux_2_17_x86_64.whl`

`SHA256SUMS` covers both wheels and the evidence archive.

Normalised analysis records from macOS and Linux agree exactly on outcome,
refusal codes, boundary states and field presence, and within pre-written
per-model tolerances on every numerical field.

## Known limits

The sequential Mendell–Elston approximation used above two-person families for
the binary and mixed models has not been bounded at the intended family sizes,
prevalence and censoring pattern. Several-component support is bounded by
demonstrated matrix properties: exactly dependent bases are refused, and no
precision rule yet covers bases that merely lie close together. The bivariate
model is limited to two traits by construction.
